# E one-time stratified challenge: inference completed and passed frozen replay

After the final version was settled as r3 and the 75-item frozen package was produced, 125 items were automatically drawn from the original internal calibration. The first batch's seed 42, screening conditions, ID hash ordering and 4:1 order were reused; questions or answers were not previewed one by one, and there was no manual selection.

- 100 candidates: offline EM=0, with the reference passage appearing in the actual C1 Top-5.
- 25 controls: offline EM=1.
- In calibration, 2,388 / 2,848 items respectively meet the above automatic conditions. Candidates are not equal to utilisation human labels, and controls are not equal to human-confirmed correct.
- All 15 source shards and the original split were re-verified, and normalized question groups containing seen IDs were excluded; the 125 fixed IDs and source fingerprints are recorded in `manifest.json`. These IDs are now registered as a challenge set already used by E, and samples must not be swapped later because of results.
- The final version, inference fingerprint and 75-item package are all bound to r3. The GPU package and Notebook have been executed; on 2026-10-21 the 19 raw exported files were collected, and the 250 results passed frozen replay; human labels for the final outputs are still pending confirmation.

`inputs/nq125_runtime.jsonl` contains only runtime fields such as the question, C1 and the actual Top-5; `inputs/nq125_c1.jsonl` keeps the offline reference scoring data; `offline/strata.jsonl` is used only for stratification and pending-review registration. Console output is only counts and fingerprints.

Here "unseen" refers only to the established exposure record of E component development. Isolation of these IDs from the team's Diagnosis training use still needs coordination, and Wikipedia page / semantic near-duplicate isolation has not yet been established; an independent test of the whole system cannot be claimed. The plan only adds runs of v7 and the final r3, C1 is reused, and the strategy is not changed after completion. The union of all changed answers is handed to the user for confirmation; reviewing only changed answers does not yield whole-batch full semantic accuracy or full repair recall.
