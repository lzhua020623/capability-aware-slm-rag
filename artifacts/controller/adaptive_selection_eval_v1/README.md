**两步都按登记规则通过。**
- confirm 方向检验：相对 B+BM25 净 **+48**（修好 97 / 改坏 49）。
- Test 采纳：相对 B+BM25 净 **+238**（修好 521 / 改坏 283），精确 McNemar p = 3.8e-17。

## 披露

- **使用次数：** 这是 confirm 第 5 次使用。Test 此前已被路线 1 和 BM25 规则使用，并逐题分析过；这是又一次披露的使用。
- **评分顺序：** confirm 先评分，通过方向检验后才对 Test 评分。Test 判官只跑了这一批，其中 1 条因限流失败，重跑补齐。
- **选取乐观：** 选定配置是在扫描集交叉验证表上按登记规则挑出来的，挑选本身带一点乐观。confirm 和 Test 的结果都不低于扫描集的预估。
- **没有事后换方案：** Test 上固定 5 种上下文选择器（+2.34）高于选定策略（+2.14），但 confirm 上顺序相反（+1.11 对 +1.97）。按 Test 换方案就等于在 Test 上调参，所以没有换。
- **选定点省成本不多：** 选定点相对固定 5 种上下文只略省成本。自适应预算的省成本效果体现在低预算的工作点：θ 0.39、τ 0.6 每题只多生成约 1 次，Test 上 +1.42，和固定 8 种上下文投票（4.41 次，+1.39）相当。
- **前置门控未生效：** 选定点 θ = 0，即不按失败概率跳过任何题，自适应只来自一致性停止。前置门控在低预算工作点上才起作用。
- **离线回放，尚未接入产品：** 结果由已生成的答案离线回放得到，和 BM25 规则接入产品之前的做法相同。产品代码还没有接入；接入后要先在 confirm 上做逐题等价检查。
- **数据边界：** 金答案只在本地使用。GPU 服务器只收到题号、问题和段落 ID。
