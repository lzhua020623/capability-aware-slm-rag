## 判断口径与限制

1. 按问题实际询问的实体、关系、事件及限定词审查，而非把gold字符串视作不可质疑的事实。接受姓名变体、数字写法和确实回答问题的合理替代答案。
2. 以提供的历史段落为主要语境；明确标记时间、地区和题意范围。A01、A26、B25、B29等历史快照判断不代表当下事实正确，未据新网页静默改写数据集日期。时间范围本身仍须团队确认。
3. 仅在参考可疑或关系不明确时额外查询公开来源。外部资料只用于本次离线审查，未加入模型运行上下文，没有新增教师/API或GPU实验。
4. “不确定”保留歧义，不默认按错误处理。过宽答案、需要完整名单的回答、演员/角色、省份/国家及发布日期/车型年份等，先把口径差异写清楚。
5. L4弃答仍记为QA未答对；当oracle段落确实缺信息时，另标 `oracle_insufficient`。这类情况不能解释为小模型拿到充分证据后仍不会回答。C1的原始Top-5未在本次重新审查，不能据此评价C1弃答是否合理。
6. 本次没有重审L3，也没有重做6,000题判官评测，因此不能用本次表格重估L3/L4的配对差异或宣称干扰效应已经人工验证。
7. 输入工作簿称使用固定种子分层抽样；本次核对样本与冻结归档的逐题内容，没有独立重建抽样随机种子。

结论应写成：**原先的恢复与持续失败集合同时混有真实模型错误、参考错误、证据不足、时效和判官口径问题；当前“候选能力边界”还不能升级为人工确认的模型能力边界。** 冻结原始结果保留，复核作为旁表。优先裁定31题待定项及上述影响归因的参考问题，再决定是否调整正式评测口径。

## 文件与复现

- `source.xlsx`：用户给出的工作簿原件副本，字节哈希写入manifest。
- `reviewed.xlsx`：只填写P–S四列，A–O的题目、答案、判官结论、证据原文全部保留。复核区域调整换行、列宽和相应行高以容纳意见。
- `reviews.jsonl`：100条助手意见、稳定sample_id、原始Excel行号、A01–A50/B01–B50编号、证据段落哈希、理由及外部来源。
- `summary.json`：按分组汇总、待定编号及原“全部未恢复”子组。
- `manifest.json`：来源、范围和非人工确认声明。原始实验的`recoverability_oracle_v1/`文件及其校验清单没有修改。
