# r4 结果与最终版本选择：采用冻结 r3

2026-10-20，最后一轮 r4 在固定 8 条开发样本、四组中完成 32 条真实输出，共 38 次生成。全部记录通过冻结代码 CPU 回放，工程门槛通过；预先声明的 N31／N48／N12 回归仅 N12 通过。**按运行前的规则，最终组件实验采用 r3，不追加 r5。**此决定先于查看本轮 EM；不能将这 8 条已见开发样本当独立效果评估。

## 三项预先声明的回归

| 样本 | 预期行为 | r4 实际行为 | 验收 |
