## Interface examples

```python
from src.compensation.controller_adapter import generation_repair
from src.compensation.qwen_repair import QwenRepairGenerator

# Upstream is responsible for constructing the request and the decision with Probe completed; reuse the model during serving.
generator = QwenRepairGenerator()
result = generation_repair(request, decision, generator,
                           strategy="extractive_reanswer")  # NQ experiment
```

```python
from src.compensation.nli_repair import MNLIVerifier
verifier = MNLIVerifier()
result = generation_repair(request, decision, strategy="fever_nli",
                           verifier=verifier)  # FEVER independent model experiment
```

Both are explicitly selected new experimental options; they do not modify upstream routing or silently promote the default strategy. `independent_support_status=nli_entailment/nli_contradiction` represents the independent model's judgement and is still not human ground truth. Returning the original answer also does not mean the original answer has been confirmed.
