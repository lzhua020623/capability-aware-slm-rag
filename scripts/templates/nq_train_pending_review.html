Review notes and label criteria

Correct: the original answer is semantically correct for the question; it need not match gold word-for-word. Utilisation: the original answer has a substantive error, or omits key content needed to answer, while Top-5 support is sufficient and clear. Accessibility: the needed information is present, but conflict, noise, or presentation makes it hard to use. Insufficiency: Top-5 lacks information needed to answer. Partial correctness is not automatically Utilisation; still confirm item by item whether the missing content is essential.

Time-sensitive questions are reviewed at the frozen-corpus date. Flag doubtful references separately; save as deferred when you cannot decide. Deferred is a review status, not a fifth runtime primary label.

Human conclusions start blank. “Adopt assisted suggestion as draft” requires an explicit click and does not complete confirmation. Editing a confirmed record returns it to draft. Browser drafts stay in this browser only; after finishing a batch, export JSON as backup; import the same-version file when changing browsers or computers.
